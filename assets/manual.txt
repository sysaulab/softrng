## DESCRIPTION
SoftRNG is a modular suite of command‑line tools for generating, filtering, and testing random number streams.  
Each tool is prefixed by its role:

- **s-** : Sources – produce data (no stdin required).
- **f-** : Filters – read stdin, transform, write stdout.
- **t-** : Terminators – consume stdin, do not produce output (or produce summary).

Pipelines are built by connecting these tools. For example:
`s-entropy | f-hex | f-limit 1K | t-hole`

## SOURCES (s-)

| Command | Description |
|---------|-------------|
| `s-entropy` | High‑quality entropy from the kernel (`getrandom`). Outputs raw binary. |
| `s-seedy64` | Continuous chaotic stream from the SEEDY64 mixer. |
| `s-seedy64-reset` | Outputs one 64‑bit value from a *fresh* SEEDY64 instance each iteration. Designed specifically for testing independence between consecutive picks. |
| `s-file <FILE> [OFFSET]` | Outputs raw content of `FILE`, starting at `OFFSET` (default 0). |
| `s-zeros` | Infinite stream of zero bytes (as little‑endian 64‑bit words). |

## FILTERS (f-)

| Command | Description |
|---------|-------------|
| `f-file <FILE>` | Tee stdin to `FILE` while passing through to stdout. |
| `f-hex` | Convert binary stdin to lowercase hexadecimal (two hex digits per byte). |
| `f-limit <SIZE>` | Pass only the first `SIZE` bytes. `SIZE` supports suffixes: `k`, `m`, `g`, `t` (decimal) or `K`, `M`, `G`, `T` (binary, e.g., `1M` = 1 048 576). |
| `f-peek` | Pass stdin to stdout while displaying a live progress bar on stderr: hex preview of first 8 bytes, total bytes read, and throughput. Refreshes at ~30 Hz with negligible overhead. |
| `f-qxo64` | Table‑based PRNG (QXO64). Requires a 2 MiB seed from stdin. Outputs an endless stream of 64‑bit words. If the output pipe is closed (e.g., `head`), the program exits cleanly (handles `BrokenPipe`). |

## TERMINATORS (t-)

| Command | Description |
|---------|-------------|
| `t-hole` | Discard all input (like `/dev/null`). |
| `t-test-bits [BITS]` | Bit‑spectrum test: reads 64‑bit words and counts unique low and high halves (each masked to `BITS` bits). Default `BITS=32`. Options: <br> `--max-stage <N>`: stop after stage N (0‑10, default 10). <br> `--log <FILE>`: write CSV progress logs to `FILE`. <br> `--results <FILE>`: final stage scores file (default `bspec32.txt`). <br> `--quiet`: suppress stderr progress updates. <br> `--update-interval <SEC>`: progress update frequency (default 0.1 s). <br> **Memory note**: For `BITS=34`, the bitset requires ~2 GiB RAM. If your system lacks enough memory, reduce `BITS` or use `--max-stage` to stop earlier. |

## EXAMPLES

```bash
# Generate 1 MiB of entropy, convert it to hex, and save to file
s-entropy | f-limit 1M | f-hex > entropy.hex

# Monitor throughput of a long-running generator
s-seedy64 | f-peek > /dev/null

# XOR two streams (experimental)
cat plaintext.bin | f-merge 's-entropy' > cipher.bin

# Multiplex a stream (experimental)
cat data.bin | f-multi 'gzip > data.gz' 'sha256sum > hash.txt'
