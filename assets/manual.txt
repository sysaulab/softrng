## DESCRIPTION

SoftRNG is a modular suite of commandline tools for generating, filtering, and testing random
number generators. It consists of a set of core commands (written in Rust) mainly destined to manipulate data streams.

Sources of data starts with the prefix "s-". They do not expect any data, they only provide data. Filters, who read, manipulate and write sits in the middle. They use the prefix "f-". Finally, terminators uses the prefix "t-". It is therefore easy to type a prefix followed by tab to see the tools available.

The most useful tools to me are f-peek and f-prng-qxo64 I used to develop and test Seedy64, who will inform you about the speed of data coming across the pipe in addition to show you a window into the data ging through. I also included my chaotic portable seeding generator with the QXO64 amplifier to test small samples of slow generators and amplify them through a simple xor operations.

# COMMANDS


| SOURCES (s-) | |
| --- | --- |
| s-ent-getent           | High‑quality entropy from the kernel (getrandom).|
| s-ent-seedy64          | Continuous entropy from the SEEDY64 chaotic mixer.|
| s-ent-seedy64-reset    | Single 64‑bit picks from fresh SEEDY64 instances, to test decorrelation between picks.|
| s-file <F> [OFFSET]    | Output raw content of file F from optional offset.|
| s-zeros                | Endless stream of zero bytes (as u64 words).|

|FILTERS (f-) | |
| --- | --- |
| f-file <F>             | Tee stdin to file F while passing through.|
| f-hex                  | Convert binary stream to hexadecimal (lowercase).|
| f-limit <N>            | Limit output to N bytes (accepts K, M, G, etc.).|
| f-merge <CMD>          | XOR stdin with the output of shell command CMD.|
| f-multi <CMD1>...      | Multiplex stdin to multiple shell branches.|
| f-peek                 | Display throughput and hex preview on stderr.|
| f-prng-qxo64           | Table‑based PRNG; requires 2 MiB seed via stdin.|

| TARGETS (t-) | |
| --- | --- |
| t-hole                 | Discard all input (like >/dev/null).|
| t-test-bits [BITS]     | Bit‑spectrum test. It tests distribution of N‑bits words up to completeness. Defaults to 32 bits |
